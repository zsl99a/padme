# 008 - 合规与红线

## 硬红线(命中即放弃)

1. 法律红线:赌博、色情、毒品、武器、传销、洗钱、偷税/漏税/虚开发票、销售侵权商品、未经授权使用他人品牌/商标/肖像。
2. 数据合规底线:爬取他人平台用户数据再变现。
3. 范围:中国大陆、老板居住地、业务发生地,任一地区法律明确禁止即命中。

## 风险登记(不拒绝,落档前必须显式)

登记项:平台 ToS 引用 / 封号概率 / 资金亏损预算 / 备份合规渠道。

- 违反平台 ToS(批量注册、刷量、刷评论、虚假交易、矩阵账号等)。
- 平台对大陆 IP/身份不友好。
- 多账号矩阵(平台明令禁止时,业务分散 + 实名独立 + 资金分散)。
- 地下钱庄 / 灰度跨境结算(汇率损耗、税务、冻卡风险披露;合规通道优先,见 README 收款通道速查)。

## 灰色机会(gray 标签)

- 套利、撸毛、平台间转售/拼车/共享订阅:标 `gray`,不设分数上限。
- 落档前 3 件事:风险与红线节完整 / 资金亏损预算明确 / `docs/ACTION-PLAN.md` 决策记录里有"接受 X 机会的灰度风险"字样。
- 未满足任一条 → 进 `_parking-lot.md` 待签字。

## 地域标签

- 每个机会档案 frontmatter 必须含 `region` 字段:`global` / `us` / `cn` / `eu` / `sea` / `jp` / `hk` / `us+cn` 等。
- 业务发生地 + 老板居住地法律冲突时,默认按老板居住地最严;老板明确豁免可按宽松地区执行,豁免记录进 `docs/ACTION-PLAN.md` 决策记录。
- 同一机会不同地区可独立落档:`X(US 版)` / `X(CN 版)`。
