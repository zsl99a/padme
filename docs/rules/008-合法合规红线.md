# 008 - 合法合规红线

## 目的

不踩法律和平台底线,保护工作区使用者。

## 适用范围

所有机会。

## 具体规则

### 1. 法律红线(任一命中即拒绝)

- 任何国家/地区法律明确禁止的商业行为。
- 涉及赌博、色情、毒品、武器、传销、洗钱。
- 偷税/漏税/虚开发票。
- 销售侵权商品(盗版、假货、未授权数字内容)。
- 未经授权使用他人品牌、商标、肖像。

### 2. 平台红线(任一命中即拒绝)

- 平台 ToS 明确禁止的行为(批量注册、刷量、刷评论、虚假交易)。
- 平台所在地区对中国 IP 全面封锁且无合规通道。
- 需要多账号矩阵但平台明令禁止多账号。

### 3. 灰色地带(降级处理)

- 套利(平台 A 价格 < 平台 B):不直接拒绝,但必须在档案「风险与红线」节写明:
  - 平台政策未来变化风险
  - 资金占用
  - 合规边界
- 撸毛(以获取空投/补贴为主要目的):同上,必须显式写「撸毛」标签。
- 平台间转售 / 拼车 / 共享订阅(违反 ToS 但不违法):**分数上限 7.5**,必须在档案中:
  - 显式标 `gray` 标签
  - 风险与红线节明确写「上游账号随时被封」+「资金亏损可接受」+「必须有备份合规渠道」
  - 优先选「采购低价区账号 / 拼车」路径,而非「直连官方 API 批量转售」

### 4. 跨境支付

- 必须可结算到中国大陆可用的渠道(USDT / 香港账户 / Wise / Payoneer / 平台直结等),否则降级。
- 不主动做需要「地下钱庄」类通道的机会。

### 5. 数据合规

- 涉及用户数据的机会必须评估 GDPR / 中国《个人信息保护法》合规。
- 不收录「爬取他人平台用户数据再变现」类机会。
