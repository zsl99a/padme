# 008 - 合规与红线

## 红线(唯一决策门)

机会不得违反中国大陆、老板居住地、业务发生地任一地区的**法律法规**。法律未明确禁止的范围,不另行设限。

## 灰色机会(gray 标签)

- 套利、撸毛、平台间转售/拼车/共享订阅等灰色地带机会:标 `gray`,不设分数上限,落档不拒绝。
- 落档前 3 件事:风险与红线节完整 / 资金亏损预算明确 / `docs/ACTION-PLAN.md` 决策记录有老板签字字样。
- 未满足任一条 → 进 `_parking-lot.md` 待签字。

## 地域标签

- 每个机会档案 frontmatter 必须含 `region` 字段:`global` / `us` / `cn` / `eu` / `sea` / `jp` / `hk` / `us+cn` 等。
- 业务发生地与老板居住地法律冲突时,按老板居住地最严;老板明确豁免可按宽松地区执行,豁免记录进 `docs/ACTION-PLAN.md` 决策记录。
- 同一机会不同地区可独立落档:`X(US 版)` / `X(CN 版)`。
