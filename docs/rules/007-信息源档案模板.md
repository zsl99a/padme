# 007 - 信息源档案模板

## 目的

记录每个被引用的信息源的可信度、刷新频率、覆盖领域。

## 适用范围

所有 `docs/sources/<name>.md`。

## 具体规则

### 1. 必填字段(YAML frontmatter)

```yaml
---
type: source
name: <信息源短名>
category: official | first-hand | media | community | aggregator
url: <主链接>
status: active | stale | dead
last_checked: YYYY-MM-DD
refresh_cadence: daily | weekly | monthly | on-event
---
```

### 2. 正文必填节

- **覆盖领域**:做什么的、覆盖哪些赚钱话题。
- **可信度**:历史命中率、是否有过错误信息案例。
- **抓取方式**:手动 / RSS / API / 爬虫。
- **典型引用**:3-5 条历史上有价值的链接。

### 3. 索引

`docs/sources/README.md` 按类别列出所有信息源。
