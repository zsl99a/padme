# 016 - 短视频/RPM 数据归属 + 海外可行性

## 目的

中国大陆短视频/自媒体平台(视频号、抖音、公众号、小红书、快手、B 站)的 RPM / CPM / 千次分成数字常被笼统引用,导致张冠李戴("视频号千次 12 元" 实际是孤证,被当作行业标准);海外用户"开通账号"与"开通商业功能"是两步,海外身份在"加入分成计划 / 收钱"第二步通常被拒。本规则强制:RPM 类数字必须明确归属平台 + 海外可行性必须区分"开通账号"与"加入分成计划 / 收钱"。

## 适用范围

所有涉及以下任一平台的机会档案:

- 视频号(微信视频号 / 视频号小店 / 视频号直播)
- 抖音 / 抖音极速版 / 火山小视频
- 公众号(订阅号 / 服务号)
- 小红书 / 哔哩哔哩 / 快手
- 视频号橱窗 / 视频号直播带货
- 任何短视频/图文平台的"千次播放分成" / "流量主" / "创作分成"

## 具体规则

### 1. RPM / CPM / 千次分成数字归属

- **RPM 类数字必须明确归属平台**:
  - 视频号 RPM ≠ 抖音 RPM ≠ 公众号 RPM ≠ 小红书 RPM
  - 同一作者在多平台的 RPM 通常差 5-20x
  - 档案中"千次 X 元"必须前缀"X 平台"(如"视频号千次 12 元"、"公众号千次 30 元")
- **官方/范围/孤证三级标签**:
  - 平台不公开的收益数字,档案中必须明确"社区范围"或"单一来源"标签
  - 避免引用"具体数字"(如 12、20、30)误导老板
  - 标签模板:
    ```
    - 官方明文: video.weixin.qq.com ...(如有)
    - 社区范围: 3-20 元(基于 X 个社区帖)
    - 单一来源: 12 元(来自 X 公众号孤证,非官方)
    ```
- **平台 RPM 官方文档路径**(供检索):
  - 视频号:shipinhao 创作分成计划页面(无公开 RPM 数据)
  - 抖音:`creator.douyin.com` 创作分成计划页
  - 公众号:`ad.weixin.qq.com/guide/2228`(仅"结算日" + "7-14 工作日到账" + "三态",无具体 RPM)
  - 小红书:`creator.xiaohongshu.com` 创作分成页

### 2. 海外可行性必须分两步

海外用户(含港澳台)在大陆平台的可行性,**严格分两步**:

- **第一步:开通账号**(账号注册)
  - 海外手机号 / 港澳台证件**通常可注册**视频号、抖音国际版
  - 但部分功能受限(如视频号基础号可注册,商业功能不可)
- **第二步:开通商业功能**(分成 / 橱窗 / 带货 / 直播 + 加入分成计划 / 收钱)
  - **商业功能必须中国大陆身份证 + 微信支付绑定实名**
  - **港澳台证件不可用**(规则 008 第 1 条触线点)
  - 海外用户即使有海外 Apple ID / Google Account,也无法"绕过"

### 3. 海外"开通" ≠ "收钱"

- "开通账号" 与 "加入分成计划" 与 "收钱" 是 3 个不同阶段
- 不少大陆平台的海外政策只允许"开通 + 浏览",不可"加入分成计划"
- 任何"海外用户可做 X 平台"声明必须明确说明:
  - 可注册账号?Y/N
  - 可发内容?Y/N
  - 可加入分成计划?Y/N
  - 可收钱(到账)?Y/N
  - 收钱通道(微信支付 / 支付宝 / Payoneer / Wise / USDT)?

### 4. 粉丝门槛区分

不同场景的粉丝门槛不同,**不可笼统说"100 粉开通"**:

- 公众号短剧 CPS:100 粉(流量主门槛)
- 视频号短剧 CPS:1000 粉(短剧变现任务门槛)
- 视频号橱窗带货:0 粉
- 视频号直播带货:100 粉
- 视频号短视频带货:1000 粉
- 抖音橱窗:1000 粉
- 小红书创作分成:1000 粉

档案中必须明确区分**具体场景** + **具体门槛**。

### 5. 最低证据要求

任何 RPM / 海外可行性 / 粉丝门槛声明必须:

- 至少 1 个**官方文档**(平台官方政策页 / 招商页 / 帮助中心)
- 至少 1 个**第三方实际用户案例**(创作者复盘帖 / 知乎 / V2EX / Reddit)
- 任何"千次 X 元"具体数字必须标 [官方 / 社区范围 / 孤证] 三级

### 6. 平台政策更名同步

平台产品/功能名变更时(如"小绿书" → "贴图"),所有相关档案必须:

- 同步更新 frontmatter tag
- 同步更新正文(主档名 + 别名)
- 在"变更日志"节标注改名时间

## 踩坑记录

- **2026-06-05 Cluster 1 验证**(`subagent_tasks/cluster-1-wechat/result.md` §6.1 + §6.2):
  - **"开通视频号" ≠ "开通商业功能"**:海外/港澳台手机号可注册视频号基础号(发视频、浏览),但商业功能(分成/橱窗/带货/直播)必须中国大陆身份证 + 微信支付绑定实名,港澳台证件不可用。原档 shipinhao-revenue-share 的"中国个人 2026 收款路径"节需重大修正,这是强合规边界。
  - **"千次播放 X 元"是平台黑箱**:视频号官方文档**不公开 RPM 数据**;社区/媒体给的都是范围值(3-20 元)或孤证(12 元)。任何具体数字(12/20/30)都应标注"社区估计,非官方"。
  - **"100 元起结算"是流量主通用说法但官方未明文**:官方 `ad.weixin.qq.com/guide/2228` 只提"结算日"+"7-14 工作日到账"+"结算中/已结算/付款中"三态,无"100 元起结"字样。社区传说 100 元起结可能是单笔提现门槛,但官方未明文。
  - **小绿书 → 贴图 已更名**:2026 微信正式更名"小绿书"为"贴图",新增"贴图号"分类(与视频号/公众号平级),全场景流量倾斜。
  - **视频号橱窗保证金:基础 100 元 + 浮动 0-30000 元**:2024 修订版条款;非"100-1000 元"范围值(原档模糊)。
  - **公众号场景 vs 视频号场景 的粉丝门槛不同**:5 个不同门槛(短剧 CPS 100/1000 粉、橱窗 0 粉、直播 100 粉、短视频带货 1000 粉),档案中需明确区分,不可笼统说"100 粉开通"。
  - **wechat-shipinhao-revenue-share 评分从 8.7 降至 7.0**:理由是"千次阅读 12 元"和"万次播放 30 元"是孤证且与官方/社区范围值(3-20 元)不符;"100 元起结算"未在官方文档出现;海外用户不可加入分成计划是严重合规问题(本规则 §2 + §3 触线点)。

- **2026-06-05 Cluster 1 验证**(`subagent_tasks/cluster-1-wechat/result.md` §5 行动建议):
  - **Top 1 修正机会**:**wechat-shipinhao-revenue-share**(从 8.7 → 7.0,降 1.7 分),本规则强制在所有大陆平台档案中应用同样的 RPM 三级标签 + 海外可行性两步区分。
