# 013 - 案例引用准确性验证

## 目的

机会档案中常引用第三方 case study / 收入数字(IH 帖、GetLatka、TrustMRR、媒体专题)来支撑"现实数据奖励"维度的 +0.5~+0.8 加分。但这些引用极易出错:数字张冠李戴、公司名混用、订阅数过期、订阅数是估算非实测。本规则强制每个数字案例都必须**直接抓取并核对原始来源**,避免"看起来相关"的并置误导老板。

## 适用范围

所有机会档案,凡是涉及以下任一数字案例:

- "X 公司 / X IH 用户 / X 创作者 月入 $Y"
- "X 频道有 Z 订阅" / "X 产品 ARR $W"
- "X 平台 Y 类目有 Z 创作者月入 $W"
- "X 服务被 Y 客户使用" / "X 产品 N 用户"
- 任何"现实数据奖励" +0.5~+0.8 加分依据

## 具体规则

1. **数字案例必查三要素**:每个数字案例在档案"参考来源"节必须给出:
   - **原始一手 URL**:创始人/产品方/IH 原帖 / 公司公告 / Crunchbase / TrustMRR dashboard
   - **抓取日期**:精确到日(YYYY-MM-DD),数字时效性 < 6 个月为佳
   - **数字所属主体**:明确"X 数字是 Y 公司的,不是 Z 公司的",避免张冠李戴
2. **二手汇总降级**:以下来源**不构成第一手**:
   - Newsletter 教程站、博客对比站(如 readless.app、EliteWealthPlan)
   - GetLatka、TrustMRR 的"行业汇总"页(除非有具体公司链接到原始 dashboard)
   - 媒体"行业总览"专题
   - 同一作者不同平台账号
3. **IH 匿名案例谨慎采信**:
   - 实名 IH(@xxx 实名)算第一手
   - 化名 IH(@xxx)算第一手但需标注"未实名,谨慎采信"
   - 仅"创始人公开说"无链接,不算第一手,视同第二手
4. **订阅/粉丝/用户数必须直接查源**:
   - YouTube 频道订阅数:必须**直接抓 YouTube 频道主页**,不依赖 SocialBlade(可能已删除/更名)
   - Twitter/X 粉丝数:必须**直接抓 X 个人页**
   - 用户数:必须**直接抓产品主页 / dashboard**
5. **同一案例不可换名重复用**:
   - 一个公司/产品的数字,只能用于它所属的业务类型
   - 反例:把转录软件 Mingogo 当作"AI 翻译 SaaS"案例 → 数字属错业务
   - 任何"换名复用"在档案校验时会自动扣分
6. **公司估值/规模验证**:
   - 估值数据必须有 Crunchbase / PitchBook / 第三方财经媒体验证
   - 仅有"$X Series B"不足以推算"估值 $Y"
   - 未独立验证的估值不作为机会评级关键证据
7. **营销话术降级**:
   - 平台/公司自家撰文中的"击败 N 家竞品"应视为营销话术,降级为"被 X 客户选为供应商"
   - 第三方独立报道(TechCrunch / Bloomberg)引用的"击败"才算硬证据
8. **数字冲突处理**(扩展 003 §4):
   - 来源间数字差距 > 50%:再找第 3 来源,或标注"区间"而非"定值"
   - 数字与主体业务不匹配(如把 A 公司数字归到 B 公司):**不构成独立来源**
   - 数字与时间窗口不匹配(如把 2024 数字当作 2026 现状):标 `(stale)` 标签

## 踩坑记录

- **2026-06-05 Cluster 4 验证**(`subagent_tasks/cluster-4-ai-saas-api/result.md` §6.1):
  - **ai-translation-saas-niche-2026 引用 GetLatka $820.8M 行业营收与 Mingogo IH 案例并置**:但 GetLatka 是 Otter/Rev 等老牌 SaaS(非新入场 AI 翻译);Mingogo IH 帖是"做窄做深"哲学(无收入数字)。**教训**:第三方 case study 引用必须验证收入数字是否存在,不能凭"看起来相关"就并置。
  - **Mingogo 业务类型混淆**:Mingogo 实际是 AI 转录软件(非 AI 翻译 SaaS);若档案把它列为"AI 翻译 SaaS"案例,数字属错业务,违反本规则第 5 条。

- **2026-06-05 Cluster 5 验证**(`subagent_tasks/cluster-5-ai-vertical-saas/result.md` §6.1):
  - **The Smart Glasses Guy YouTube 频道 4.68K subs,不是 125K**:SocialBlade 用户页 404,但直接查 YouTube 频道主页有**最新准确订阅数**;原档 125K 是过期数据,失实 25x。**教训**:YouTube 频道数据必须直接查 YouTube,不依赖 SocialBlade。
  - **xAI $35-45/h 是 US-based,International 未明文**:xAI Greenhouse 招聘页明确区分 US-based($35-45) vs International(未明文);原档把 $35-45 当作"中文母语者时薪 ¥237-304"是**严重误导**。
  - **Praktika 真实 $12M ARR = $1M/月,不是 $2M/月**:ConsumerStartups + LinkedIn 多源报告 Praktika 在 4 个月内达到 $12M ARR(2025-03);月入 = ARR/12 = $1M/月。原档的 "$2M/月"是直接乘 12 反推,但实际应除以 12。**教训**:ARR / MRR 转换必须是 ARR / 12(不是 × 12)。
  - **Final Round AI 实际是"面试作弊"工具**:主页强调 "Crack Every Interview with Real-Time AI Assistant / 100% Undetectable / completely invisible to interviewers / LeetCode / HackerRank 实时编码辅助";任何把它列在"AI 模拟面试"赛道是事实错误。
  - **Permito 是"一次性付费"模式,不是订阅**:价格 Free / $6.9 / $14.9 / **$39(Until Approved + 60 天退款)**;原档把它描述为 "$39-90/月订阅"是定价模式错误。**教训**:定价模式必须直接查定价页,不沿用档案首次记录。
  - **EU AI Act GPAI 义务 2025-08-02 已生效**:原档只提 2026-08-02 截止日,缺失 2025-08-02 GPAI 义务生效;完整时间线 2024-08-01 进入生效 → 2025-08-02 GPAI → 2026-08-02 主要截止日 → 2027-08-02 高风险 AI → 2028-08-02 嵌入产品 AI。

- **2026-06-05 Cluster 3 验证**(`subagent_tasks/cluster-3-ai-agent-freelance/result.md` §7.2-7.4):
  - **Red Team 机会的 Mindgard $2.4M ARR / 16 人关键数据**:本次检索 Mindgard 官网未显示该数字;原档声称"创始人访谈",但未给访谈链接。**教训**:"创始人访谈"必须有可点击链接(IH 帖 / HN AMA / Twitter thread / Podcast episode),未给链接的访谈视同第二手。
  - **Voice AI Vapi "击败 40+ 竞品拿下 Amazon Ring"**:Vapi 自家撰文,Amazon Ring 客户 testimonial 只说"100% inbound volume runs through Vapi",未提及"击败 40+ 竞品"。**教训**:平台/公司自家撰文中的"击败 N 家竞品"应视为营销话术。
  - **Voice AI Vapi $500M 估值**:Vapi 官网未直接显示,只有 $50M Series B;$500M 估值可能是 Crunchbase 推算,需独立验证。
