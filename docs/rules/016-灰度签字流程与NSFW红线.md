# 016 - 灰度签字流程与 NSFW 红线

## 目的

gray 标签机会(规则 008 定义)在执行前需老板明确签字,避免 AI/自动化在法律边缘机会上"擅自启动";NSFW 类机会(AI 角色卡 / Chub / Patreon)又有额外的"国内身份禁注册"硬约束。本规则明确:gray 机会 + NSFW 机会的**启动前签字清单**,确保老板对资金亏损预算、风险红线、AI 角色定位有完全认知。

## 适用范围

所有 `tags: [gray, ...]` 或 `tags: [nsfw, ...]` 的机会档案,具体包括:

- Web3 灰度机会(质押、DeFi、DePIN、空投预期)
- 国内卖课 / 知识付费(规则 008 第 1 条触线点)
- AI 角色卡 / Chub / Patreon NSFW 创作者
- Telegram / Discord 灰色变现
- 跨境收款灰区(USDT OTC、地下钱庄)
- 任何"打政策擦边球"型机会

## 具体规则

### 1. 启动前必填签字清单

gray / NSFW 机会**启动前**(进入"立即做"或"两周内启动"档)必须满足以下全部:

- (a) `docs/ACTION-PLAN.md` 有老板明确签字字样(如 "老板:签字 2026-06-XX,启动 XXX")
- (b) 资金亏损预算明确(具体金额 + 时间窗口,如 "1 万 RMB / 3 月内可亏完")
- (c) 风险与红线节完整(列出所有可能触红线点 + 缓解措施)
- (d) 退出机制明确(资金何时撤出 / 何时降为 parking-lot / 何时归档)

### 2. AI 角色卡 NSFW 特别约束

AI 角色卡 / Chub / Patreon NSFW 创作者类机会,**额外约束**:

- (a) NSFW 业务必须**完全切到 Chub / Patreon 等海外平台**
- (b) **国内身份禁注册** Chub / Patreon NSFW 创作者账户(平台 ToS 硬约束 + 触 008 第 1 条)
- (c) 必须用海外身份(护照 / 海外居留) + 海外银行账户收款
- (d) AI 角色卡"人设"必须明确:年龄设定 18+/虚构/非真人
- (e) 国内身份仅可做 SFW 部分(公众号 AI 长文、AI 工具评测),NSFW 业务 0 接触

### 3. 灰度资金上限

- 任何 Web3 灰度机会**总投入上限** = 已确认流动资产的 10%
- 单笔 C2C 出金上限 = 5 万 RMB(规则 008 已规定)
- 月度 OTC 出金次数 ≤ 2 次(规避反洗钱监控)
- 任何机会月净收益 < $100 持续 3 月 → 暂停,进入 parking-lot

### 4. NSFW 24 月窗口期

AI 角色卡 / Chub / Patreon NSFW 创作者**预设 24 月窗口期**:

- 欧盟 AI Act 2026 已生效 + 各国 AI 法案可能进一步收紧
- **12 月时需评估**:是否转 SFW 收入占比 > 50%
- **24 月时必须**:主收入转独立站 + 邮件列表 + 自托管订阅(降低对 Chub / Patreon 单一平台依赖)
- 国内身份 0 接触(国内推广 NSFW 内容触 008 第 1 条)

### 5. 国内平台灰区(小红书/抖音/公众号)额外约束

- 任何"AI 矩阵" / "AI 内容" 在国内平台(小红书 / 抖音 / 视频号 / 公众号)运营:
  - AI 内容必须主动标注(2026-01-19 小红书社区公约 2.0 强制要求)
  - 跨平台搬运可被识别(抖音 / 公众号搬内容能识别)
  - "人感包装"的合规边界:不可伪装成真人
  - 单账号矩阵可,多账号矩阵封号风险高(平台 ToS 模糊点)

### 6. 签字文件模板

签字文件存放在 `docs/ACTION-PLAN.md`(项目根目录),模板:

```markdown
## 灰度机会启动签字

- 机会: <name>
- gray 原因: <触 008 第 X 条>
- 启动日期: YYYY-MM-DD
- 资金亏损预算: <X 万 RMB / Y 月>
- 退出条件: <何时降为 parking-lot / 何时归档>
- 老板签字: _____________ 日期: YYYY-MM-DD
```

### 7. 老板不在场 / 签字不全的灰度机会

- 默认 **不启动**,即使评分 ≥ 7.5
- 进入 parking-lot 等待老板下次主动签字
