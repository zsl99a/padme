# 006 - 机会档案模板

## 目的

保证每个机会档案信息完整、可被未来会话直接拿来执行。

## 适用范围

所有 `docs/opportunities/<name>.md`。

## 具体规则

### 1. 必填字段(YAML frontmatter)

```yaml
---
type: opportunity
name: <机会短名,kebab-case>
status: active | stale | archived
score: <0.0-10.0>
freshness_class: volatile | seasonal | structural
first_seen: YYYY-MM-DD
last_updated: YYYY-MM-DD
region: <global|us|cn|eu|sea|jp|hk|us+cn|...>
tags: [tag1, tag2]
---
```

### 2. 正文必填节

| 节 | 必填 | 说明 |
| --- | --- | --- |
| 一句话定位 | ✅ | 谁给谁、用什么、收什么钱 |
| 自动化路径 | ✅ | 工具栈 + 关键步骤(可贴 mermaid) |
| 评分明细 | ✅ | 按 002 标准逐项打分 |
| 启动清单 | ✅ | 账号、域名、API Key、首批内容、首批投放 |
| 风险与红线 | ✅ | 触线点 + 缓解措施 |
| 监控指标 | ✅ | 哪些数字能告诉我「这件事还在赚钱」 |
| 参考来源 | ✅ | 至少 2 条,按 003 标注 |
| 复盘/亲测 | ❌ | 若已亲测则填写 |

### 3. 文件命名

- 小写英文 + 连字符:`stripe-atlas-reselling.md`。
- 中文名音译或短英文,避免文件名带空格。

### 4. 状态机

```
draft → active → (stale | archived)
```

- `active`:当前有效,正在或准备执行。
- `stale`:失效但保留以防复活。
- `archived`:明确放弃(触红线、不可自动化等)。

### 5. 与索引同步

每次新增/修改机会,**必须**同步更新 `docs/opportunities/README.md` 的索引表。
