# 003 - 信息源交叉验证

## 目的

避免单源错误信息、过期信息、虚假宣传污染档案。

## 适用范围

所有机会的「有效」「金额」「流程」声明。

## 具体规则

### 1. 最少来源数

- 「当前有效」类声明:≥ 2 个独立来源。
- 「预期收入」「所需时间」类声明:≥ 1 个第一手案例(亲自跑 / 他人公开复盘),允许 + 1 个第二手来源。

### 2. 独立性判定

以下情形**不构成独立来源**:

- 同一作者不同平台账号。
- 同一篇文章被多个聚合站转载。
- 同一新闻稿被多家媒体引用。
- 互相引用的两个 KOL。

### 3. 来源类型优先级(从高到低)

1. **官方文档/官方政策页**(平台 ToS、官方公告)。
2. **亲测复盘/技术博客**(带截图、代码、流水)。
3. **权威媒体**(主流财经/科技媒体)。
4. **社区/论坛一手讨论**(Reddit、HackerNews、V2EX 原帖)。
5. **聚合站/Newsletter 二手汇总**(最低权重)。

### 4. 冲突处理

- 来源间数字差距 > 50%:必须再找第 3 来源,或标注为「区间」而不是「定值」。
- 来源间流程冲突:以官方文档为准。

### 5. 来源落档

每条来源必须在机会档案的「参考来源」节给出:
- 链接
- 类型(按上面 5 级)
- 抓取日期
- 关键引用句(1 句话)

并在 `docs/sources/<name>.md` 维护信息源档案(见 [007](./007-信息源档案模板.md))。
