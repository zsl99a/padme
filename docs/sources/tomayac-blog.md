# Tomayac Blog (Thomas Steiner)

## 覆盖领域

Google 开发者关系(DevRel)工程师个人博客,高频写 W3C 新标准、Web Monetization、浏览器 API、Progressive Web Apps、Chrome 实验特性。

## 可信度

- **极高**:作者是 W3C 工作组成员,内容带 RFC/spec 链接,可直接验证。
- **特点**:文章结构标准(背景→规格→代码→实战),且常附 demo。
- **数据性**:偏技术规范解读,收入类数字披露少。

## 抓取方式

- **HTML 抓取**:Firecrawl 抓首页 / `/tags/<tag>` 页
- **RSS**:`https://blog.tomayac.com/feed.xml`(若启用)
- **GitHub**:作者同步发布源码到 GitHub,可联动读 commits

## 踩坑

- 作者个人博客,频率约 2-4 篇/月,适合做"标准进展"信号源,不适合做"日更赚钱灵感"。
- 部分 post 是 Google I/O / BlinkOn 演讲整理,信息密度低于第一手公告。
