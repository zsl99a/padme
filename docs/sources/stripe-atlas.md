# Stripe Atlas

## 覆盖领域

美国公司注册基础设施(Delaware C Corp / LLC),用于:

- 设立美国主体收美元(Stripe / Gumroad / SaaS)
- 申请 Mercury / Relay 银行账户
- 申请 ITIN / EIN
- 进入 AWS / Mercury / Xero / Orrick 等 $50K+ 折扣生态

## 可信度

- **极高**:Stripe 官方,合规且法律支持齐全。

## 关键事实(2026-06-04 抓取)

- **$500 一次性** 设立费(包含政府费 + 第一年注册代理)
- **$2500** Stripe 产品 credit(第一年)
- **$50,000+** 合作伙伴折扣(Mercury / Xero / AWS / Orrick / 各类 SaaS)
- 支持 C corp / LLC / Subsidiary
- 设立后 1 个工作日完成(加急)

## 抓取方式

firecrawl scrape 主页 + 关注 perks 更新。

## 踩坑

- **不是免费的**,$500 是真实成本(且不退还)。
- **税务申报**需自己处理(或找美国会计师,另付 $500-2000/年)。
- **不解决中国税务居民身份**,中国税务居民全球收入需申报。
- **需要 SSN/ITIN** 才能开 Mercury,否则部分银行账户开不了。
