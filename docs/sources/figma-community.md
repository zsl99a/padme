# Figma Community (官方)

## 覆盖领域

Figma Community 是 Figma 官方资源市场。覆盖 **Figma 模板/插件**赛道。2026 年现状:
- **免费分发**:Figma Community File/Template/UI Kit 全部免费
- 变现方式:不是直接分成,而是**通过插件付费**(Plugin Developer Program) 或 **Figma Marketplace**(2026 年新)
- Figma 2026 新产品:Figma Make / Figma Weave / Figma Sites / Figma Buzz / Figma Slides,生态扩张
- State of the Designer 2026 报告显示设计师 AI 工具采用率提升

## 可信度

- **Figma 官方报告**:State of the Designer 2026(数据权威)
- **Figma Community**:真实可下载量
- **Figma Plugin 开发者案例**:有 60,000+ 安装的插件案例(Reddit r/FigmaDesign)

- Firecrawl scrape figma.com
