## 风险与红线

- **个人品牌依赖**:0 粉起步需 3-6 月冷启动;**不要等到"准备好"再开始**,用 1 周边做边录边发。
- **课程同质化**:vibe coding 课程 2026 大量涌现,**差异化在"垂直岗位 + 真实任务"**,不教"如何写代码",教"如何用 AI 完成你的工作"。
- **Anthropic 政策变更**:Claude Code 2026 多次调整 API 计费与使用限制;**课程内容每月更新**(避免过时)。
- **退款率高**:Maven / Gumroad 30 天无理由退款;课程质量差退款率 > 20% 会被平台降权。
- **"教学" ≠ "卖课"**:不要承诺"7 天做出 SaaS 估值 $1M"等夸大;Maven 平台对夸大宣传审查严。
- **Maven 30% 抽成**:Gumroad 95% 到手但获客难;**矩阵化**:Gumroad 自服务 + Maven cohort-based。
- **学员"中国"身份**:Maven / Gumroad 接受中国个人收款路径(Lemon Squeezy + Payoneer);Patreon 限制中国身份。
- **版权风险**:不要直接用 Anthropic 官方文档当课程内容,做"加工 + 实战 + 案例"才安全。
- **Claude.md 工具包≠ "工具包销售"**:CLAUDE.md 本身是免费的,要卖的是"配套视频 + cohort 答疑",不是"工具包"。
