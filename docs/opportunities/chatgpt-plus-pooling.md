# ChatGPT Plus / Claude Pro 拼车平台

## 一句话定位

把 ChatGPT Plus / Claude Pro / Cursor Pro 等"单人订阅"服务拆成多人共享,按月向中国用户收费,差价即利润。

## 自动化路径

工具栈:
- 一个 SaaS 落地页(Next.js + Stripe / 支付宝扫码)
- 拼车专用脚本(账号健康监控、登录通知、流量配额)
- Telegram 群(交付 + 客服)

关键步骤:


## 风险与红线

- **ToS 风险**:OpenAI / Anthropic / Cursor ToS 明确禁止账号共享/转售。账号随时可能封禁,**收入不稳定**。
- **支付通道**:Stripe 对此类订阅敏感,需要新主体或备选支付。
- **同质化竞争**:V2EX 上"白送 1 个月"帖频繁,价格战激烈。
- **建议**:用低成本域名 + 极简落地页快速试错;若被封号,转 LLM API 中转(参见 `llm-api-reselling-cn.md`)。

## 监控指标

- 单席位净利润(健康线 > 50%)
- 退款率(健康线 < 5%)
