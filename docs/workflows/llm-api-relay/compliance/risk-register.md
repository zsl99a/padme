# 风险登记册

> 配套机会档案:`../../../opportunities/llm-api-reselling-cn.md`

## 风险等级

🔴 高(直接关停)
🟡 中(需要立即缓解)
🟢 低(可接受,定期 review)

---

## R1. 上游账号被封 🔴

- **描述**:OpenAI / Anthropic 检测到"非直连使用"或"账号池行为",封禁 API key
- **影响**:服务中断 1-7 天,无收入
- **概率**:中(每月 1-3 次)
- **缓解**:
  - 至少 3 个独立上游渠道(OpenAI / Anthropic / Gemini / DeepSeek)
  - 每个渠道至少 2 个账号冗余
  - 自动切号脚本(检测到限流立即切换)
  - 上游检测到的"非直连 IP"问题:每账号固定住宅 IP
- **触发条件**:上游调用成功率 < 80% 持续 1 小时
- **响应**:见 `../ops/incident-runbook.md#R1`

## R2. Stripe 风控封号 🟡

- **描述**:Stripe 对 AI 类订阅敏感,易触发风控
- **概率**:中(6 个月内 30% 概率)
- **缓解**:
  - 备选 Creem / Paddle / LemonSqueezy
  - 备选 USDT 收款
  - 主体:用 Stripe Atlas 美国 LLC(独立主体)
- **触发条件**:账户被 review / 资金 hold 14 天以上
- **响应**:见 `../ops/incident-runbook.md#R2`

## R3. 数据泄露 / 用户 Prompt 被卖 🟡

- **描述**:用户 prompt 被中转站打包卖 AI 训练厂商
- **影响**:用户流失 + 信誉崩溃 + 潜在法律风险(GDPR / 个保法)
- **概率**:中(取决于自己)
- **缓解**:
  - 明示日志策略(只保留 7 天,自动删除)
  - 提供"无日志模式"选项(企业用户刚需)
  - 不打包任何 prompt 卖第三方
- **触发条件**:用户公开投诉 / 媒体曝光
- **响应**:立即公告 + 删除数据库 + 通知用户

## R4. 客户用服务做违规内容(色情/暴力/诈骗) 🟡

- **描述**:客户用中转 API 生成违规内容,平台/监管追溯到中转站
- **影响**:主体被封 / 法律责任
- **概率**:中(取决于内容审核)
- **缓解**:
  - new-api 启用内容审核中间件(可对接 OpenAI Moderation / 自建 LLM 审核)
  - 单用户日用量上限(防止被滥用)
  - 收到 DMCA / 监管通知立即停账号
- **触发条件**:1 次 / 季度
- **响应**:72h 内响应,停账号 + 退余额

## R5. 模型掺水 / 暗改倍率 🟢

- **描述**:中转站以次充好赚差价(V2EX #1217490 Tanix2 复盘)
- **影响**:用户发现后举报 + 失去信任
- **概率**:低(我们自己不做)
- **缓解**:
  - 明示计费 + 后台可下载逐笔明细
  - 提供"与官方对账"小工具
  - 接受 V2EX 用户监督

## R6. 上游价格大幅波动 🟡

- **描述**:OpenAI / Anthropic 调整 API 零售价
- **影响**:毛利率骤降
- **概率**:高(每 6-12 月一次)
- **缓解**:
  - 多上游,价格对冲
  - 套餐定价留 20% 缓冲
  - 价格调整时给老用户 30 天缓冲期

## R7. 现金流断裂 🟢

- **描述**:启动资金用完还没到 first revenue
- **影响**:服务停摆
- **概率**:低(启动成本 < ¥800)
- **缓解**:
  - 老板设定月度预算上限(建议 ¥200/月)
  - 超出上限自动告警

## R8. 监管收紧 / 平台封禁 🟡

- **描述**:中国大陆对 AI 服务监管收紧
- **影响**:域名 / IP 被封
- **概率**:中(2-3 年内可能)
- **缓解**:
  - 海外备用节点(美西)
  - 多域名备案
  - 必要时转海外主体
