## 2. 重复检测结果

### 2.1 重复组 A:「公众号流量主 + 返佣 CPS」三层级

- **涉及文件**:
  - wechat-gzh-llzj-ai-writer.md(综合流量主,100 粉 + 三种变现)
  - wechat-fanyong-cps-cross-platform.md(专门返佣 CPS,90/10 抽成)
  - wechat-short-drama-cps.md(短剧 CPS,60-70% 分成,垂直细分类目)
- **重复点**:
  - 三者都讲"公众号 100 粉 → 开通流量主 → 插入广告/商品卡 → 用户付费/阅读 → 平台分账"
  - gzh-llzj-ai-writer 把返佣作为三种变现之一
  - fanyong-cps 单独扩展到视频号橱窗
  - short-drama-cps 是返佣 CPS 下的"短剧"垂直品类(短剧 CPS 走的是"小程序短剧 → IAP 支付分成",与实物返佣的结算链路不同)
- **处理建议**:**保留三个,各自定位明确**:
  - gzh-llzj-ai-writer = "AI 长文 + 流量主"通用路线
  - fanyong-cps = "全平台返佣"专门赛道
  - short-drama-cps = "短剧 CPS"垂直品类
- **推荐 lead 文件**:**wechat-fanyong-cps-cross-platform.md**(最完整,最权威;90/10 抽成有官方文档背书)
- **合并后差异点(各自独立保留)**:
  - gzh-llzj-ai-writer 重点:AI 写稿流水线 + 流量主全模式
  - fanyong-cps 重点:返佣商品选品 + 视频号橱窗
  - short-drama-cps 重点:短剧选品 + IAP 分账 + 剧方合规边界
- **理由**:三者都指向"公众号 CPS"母赛道,但实现路径、选品、分账机制都不同,合并会丢失垂直深度。**不合并,但需在每个档案的"协同"节互相链接**。

### 2.2 重复组 B:「视频号变现」两条路径

- **涉及文件**:
  - wechat-shipinhao-revenue-share.md(评论区广告分成,**纯流量变现**)
  - wechat-channel-tui-ke-2026.md(小店 + 推客,**实物电商变现**)
- **重复点**:
  - 都讲视频号
  - 都依赖视频号 100 粉门槛
- **处理建议**:**保留两个,差异化定位清晰**:
  - shipinhao-revenue-share = "创作者侧" / 流量主 / 无商品 / 自动广告
  - channel-tui-ke = "商家侧" / 招商 + 招推客 / 选品 + 履约
- **推荐 lead 文件**:**两者并列**,无主次。老板是个人创作者 → shipinhao;老板有供应链 → channel-tui-ke。
- **理由**:变现机制完全不同(广告分成 vs 商品分佣),目标用户(创作者 vs 商家)不同。**不合并**。

### 2.3 单文件独立机会

- **wechat-lvshu-public-traffic.md**(小绿书/贴图)与其他无强重复 — 它是"图文流量入口"层,与其他都形成协同(都讲"图片消息如何给视频号/公众号/返佣导流")。**不合并,作为"流量入口"独立档**。

## 6. 新规则/踩坑建议

### 6.1 新发现的踩坑(本集群验证中)

1. **"开通视频号" ≠ "开通商业功能"** — 海外/港澳台手机号可注册视频号基础号(发视频、浏览),但**商业功能(分成/橱窗/带货/直播)必须中国大陆身份证 + 微信支付绑定实名,港澳台证件不可用**。原档案 shipinhao-revenue-share 的"中国个人 2026 收款路径"节需重大修正,这是强合规边界。

2. **"千次播放 X 元"是平台黑箱** — 视频号官方文档**不公开 RPM 数据**;社区/媒体给的都是范围值(3-20 元)或孤证(12 元)。任何具体数字(12/20/30)都应标注"社区估计,非官方"。

3. **"100 元起结算" 是流量主通用说法但官方未明文** — 官方 ad.weixin.qq.com/guide/2228 只提"结算日"+"7-14 工作日到账"+"结算中/已结算/付款中"三态,无"100 元起结"字样。社区传说 100 元起结可能是单笔提现门槛,但官方未明文。

4. **小绿书 → 贴图 已更名** — 2026 微信正式更名"小绿书"为"贴图",新增"贴图号"分类(与视频号/公众号平级),全场景流量倾斜。这是 2026 重要官方信号,需在所有相关档案中同步。

5. **视频号橱窗保证金:基础 100 元 + 浮动 0-30000 元** — 2024 修订版条款;非"100-1000 元"范围值(原档案模糊)。需查 2026 现行版本确认。

6. **公众号场景 vs 视频号场景 的粉丝门槛不同**:
   - 公众号短剧 CPS:100 粉(流量主门槛)
   - 视频号短剧 CPS:1000 粉(短剧变现任务门槛)
   - 视频号橱窗带货:0 粉
   - 视频号直播带货:100 粉
   - 视频号短视频带货:1000 粉
   这是 5 个不同的门槛,档案中需明确区分,不可笼统说"100 粉开通"。

### 6.2 新规则建议(待沉淀到 docs/rules/)

- **建议新规则 011:平台"基础功能" vs "商业功能"区分** — 任何中国大陆平台的"开通",必须区分"账号注册" / "商业功能开通"两步,海外身份在第二步通常被拒,档案 frontmatter 必须明确 region + 商业可行性。
- **建议新规则 012:RPM/CPM 数据必须标注"官方/范围/孤证"** — 平台不公开的收益数字,档案中必须明确"社区范围"或"单一来源"标签,避免引用"具体数字"误导老板。

### 6.3 跨集群协同建议

- 视频号+小绿书+公众号"三件套"已是 2026 微信生态主流玩法,**建议在主档 `wechat-channel-tui-ke-2026.md` 加"协同:与 shipinhao-revenue + gzh-llzj + lvshu 形成矩阵"说明**,作为老板"立即做"路径的入口。
