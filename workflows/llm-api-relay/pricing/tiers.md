# 套餐设计

## 原则

- 透明:后台可查每一笔 token 用量
- 梯度:覆盖从"试水"到"重度"
- 无锁定:按量可永久使用,包月可随时停
- 退款:首单 7 天内可退(余额形式)

## 套餐表

| 套餐 | 额度 | 价格 | 折合单价 | 适用 |
| --- | --- | --- | --- | --- |
| 体验 | 100k tokens | ¥9.9 | ¥99/M | 试用 / 个人 / 1 个小项目 |
| 标准 | 1M tokens | ¥69 | ¥69/M | 个人 / 1-3 个项目 |
| 专业 | 5M tokens | ¥299 | ¥59/M | 小团队 / 中等量 |
| 旗舰 | 20M tokens | ¥999 | ¥50/M | 中等团队 / 多个项目 |
| 企业 | 100M+ | 联系 | ¥40-50/M | 大客户 / 月结 |

## 规则

- 所有套餐 **不区分模型**(按 input + output 总量计)
- 但有"软上限":单日 50% 额度 = 触发"高负载提醒",可调
- 月底未用完的额度 **不累积**
- 续费不涨价(除非上游 API 调价,我们也对应调)

## 隐藏项(写在 FAQ,不显眼)

- OpenAI o1 / o3 系列:**1.5x 计费**(因为上游本身贵)
- Claude Sonnet 4 (200K context):**1.2x 计费**
- Image generation(DALL-E / GPT-4o image):**按次计费**,不按 token
- Embeddings / TTS:**0.3x 计费**

## 落地页文案要点

1. 第一屏:三句话定位(自建 / 透明 / 全模型)
2. 第二屏:价格表 + 实时用量截图
3. 第三屏:技术细节(节点 / 延迟 / 兼容性)
4. 第四屏:与官方对比表
5. 第五屏:CTA(注册 / 充值)
6. 页脚:ToS 链接 / 隐私政策 / 客服
