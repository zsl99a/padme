# V2EX 创造节点 推广文案(主帖)

> 发到 https://www.v2ex.com/?tab=create 的节点

## 主帖

**标题**:
自建 LLM API 中转,支持 GPT-4o/Claude/Gemini,透明计费,无掺水

**正文**:

```
各位好,自建了一个 LLM API 中转站,放出来用:

✅ 透明计费:用多少扣多少,后台可查每一笔明细
✅ 多模型:OpenAI (GPT-4o / o1 / o3) / Anthropic (Claude 3.5/3.7/Sonnet 4) / Google (Gemini 2.5) / DeepSeek
✅ 速度:HK/JP 节点,平均延迟 < 200ms
✅ 配套:OpenAI 兼容接口,直接改 base_url 就能用
✅ 价格:比官方便宜 30-50%,按 token 计费
✅ 支付:Stripe / USDT / 支付宝
✅ 不存对话(明示日志策略)

使用方法:
1. 注册账号
2. 充值(支持按量 / 包月套餐)
3. 把 base_url 改成 https://<域名>/v1
4. 跑起来

适合:做 AI 应用的、想用 Codex/Claude Code 但账号被封的、对中转站数据安全不放心的。

不做的:
- 不卖账号、不做拼车(只卖 API)
- 不掺水、不暗改倍率
- 不搞分销代理(没空)

链接:https://<你的域名>
```

**为什么这样写**:
- 标题覆盖关键词(GPT-4o/Claude/Gemini)便于站内搜索
- 痛点直接命中 V2EX 创造节点用户(透明计费、API 兼容、延迟低)
- 主动声明"不做的"回应了 Tanix2 复盘中提到的 7 大中转站骚操作
- 没分销代理(避免站长间互相刷)
